## English

A Forge 1.20.1 expert skyblock modpack — start from nothing, master technology and magic, and defeat the final boss to craft creative-mode items.

Sky Evolution Journey brings together the vast majority of tech, magic, and (upcoming) boss mods available for Forge 1.20.1 into a single cohesive progression. Every resource must be earned from scratch on your skyblock island, with a carefully designed quest book guiding you through each age.

### Features

- **Expert progression** — build automated production lines for every material tier, weaving through technology, magic, and (upcoming) boss encounters from nothing to endgame
- **Broad mod coverage** — Applied Energistics 2, Create, Botania, Mekanism, Immersive Engineering, Thermal Series, PneumaticCraft, Industrial Foregoing, Ars Nouveau, and many more
- **Skyblock from zero** — full skyblock start with SkyblockBuilder; every vanilla resource has a crafting or automation path
- **Rich quest guidance** — FTB Quests with lore and tutorials for every major milestone
- **Modular automation** — XNet, Pipez, Sophisticated Storage & Backpacks, Functional Storage, and more for late-game logistics
- **Boss content** — coming in a future update

### Mod Count

288 mods (Forge 1.20.1)

### Installation

> **Note:** This modpack is currently in closed beta. Download is available via GitHub Releases only.

1. Go to the [Releases](../../releases) page and download the latest `.zip` file.
2. Import it into any launcher that supports the CurseForge format (CurseForge App, Prism Launcher, HMCL, etc.).

## 简体中文

一款 Forge 1.20.1 专家级空岛整合包——从零开始，掌握科技与魔法，击败最终 Boss，合成创造模式物品。

Sky Evolution Journey 收录了 Forge 1.20.1 绝大部分科技、魔法及（即将加入的）Boss 模组，形成完整的进度线。玩家从空岛上的一无所有出发，跟随精心设计的任务书，逐步走完每一个时代。

### 特点

- **专家级进度** — 围绕自动化流水线工厂展开，覆盖科技、魔法与（即将加入的）Boss 战斗，从一无所有一路推进到终局
- **广泛模组覆盖** — 应用能源2、机械动力、植物魔法、通用机械、沉浸工程、热力系列、气动工艺、工业先锋、新生魔艺等
- **真正的空岛从零开始** — 基于 SkyblockBuilder，所有原版资源均有合成或自动化途径
- **丰富任务引导** — FTB Quests 任务书，每个重要里程碑均有说明与叙事
- **模块化自动化** — XNet、Pipez、精妙系列、功能性存储等支持后期物流
- **Boss 内容** — 将在后续版本加入

### 模组数量

288 个模组（Forge 1.20.1）

### 安装方式

> **注意：** 本整合包目前处于内测阶段，仅通过 GitHub Releases 发布。

2. 导入支持 CurseForge 格式的启动器，以下启动器均支持：CurseForge App、Prism Launcher、HMCL 等。
